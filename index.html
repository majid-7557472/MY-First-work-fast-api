What are Git & GitHub?

Learn the basics of both technologies

Git

Git is a free and open-source distributed version control system designed to handle everything from small to very large projects with speed and efficiency. It was created by Linus Torvalds in 2005.

  • ✓ Runs locally on your computer
  • ✓ Tracks changes in your code
  • ✓ Works offline — no internet needed
  • ✓ Manages code history and branches
  • ✓ Free and open-source software

GitHub

GitHub is a cloud-based hosting service for Git repositories. It provides a web interface, collaboration features, and social coding tools. It was founded in 2008 and acquired by Microsoft in 2018.

  • ✓ Cloud-based platform (online)
  • ✓ Team collaboration & code review
  • ✓ Pull requests & issue tracking
  • ✓ GitHub Actions for CI/CD
  • ✓ Social features — stars, forks, followers

Key Concepts

Important terms you should know

📦

Repository (Repo)

A folder that contains your project files and the entire history of changes made to them.

🌿

Branch

A separate line of development. Allows you to work on features without affecting the main code.

💾

Commit

A snapshot of your changes. Each commit has a unique ID and message describing what changed.

🔀

Merge

Combining changes from one branch into another. Brings separate work together.

📤

Push & Pull

Push sends your local commits to GitHub. Pull downloads changes from GitHub to your local machine.

🔃

Pull Request (PR)

A GitHub feature to propose changes. Team members can review, discuss, and approve before merging.

Essential Git Commands

Most commonly used Git commands every developer should know

git init

Initialize a new Git repository in your project folder

git clone <url>

Copy a remote repository to your local machine

git add .

Stage all changed files for the next commit

git commit -m "message"

Save staged changes with a descriptive message

git push origin main

Upload your local commits to GitHub

git pull

Download and merge changes from the remote repository

git branch <name>

Create a new branch for separate development

git status

Check which files are modified, staged, or untracked

Simple Analogy 💡

📝

Git = Microsoft Word

Git is like Microsoft Word — it's the software on your computer that lets you write and save documents (track changes in your code).

☁️

GitHub = Google Drive

GitHub is like Google Drive — it's the online platform where you upload, store, share, and collaborate on those documents with others.

Summary ✨

Git is the engine — the version control tool that runs on your computer.

GitHub is the garage — the online platform where you park (host) your code, collaborate with others, and showcase your projects.

🎯 You need Git to use GitHub, but you don't need GitHub to use Git!
